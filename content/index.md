# Eventium

Composable, type-safe event sourcing for Haskell — event stores with optimistic
concurrency, pure projections, command handlers, process managers, event
subscriptions, and pluggable storage backends (in-memory, PostgreSQL, SQLite).

```
cabal add eventium
```
